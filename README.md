# Aplikasi Padel PBO

Aplikasi manajemen Padel yang dibangun dengan Java menggunakan Pemrograman Berorientasi Objek (PBO).

## Deskripsi

Proyek ini adalah tugas besar (Tubes) untuk mata kuliah Pemrograman Berorientasi Objek Semester 4. Aplikasi ini dirancang untuk mengelola informasi tentang padel, pemain, dan reservasi lapangan.

## Struktur Project

```
.
├── src/
│   └── main/              # Source code utama
├── target/                # Build output (diignore)
├── pom.xml               # Maven configuration
└── nb-configuration.xml  # NetBeans configuration
```

## Teknologi

- **Language**: Java
- **Build Tool**: Maven
- **IDE**: NetBeans

## Cara Menjalankan

1. Clone repository:
```bash
git clone https://github.com/FaizulAfiat/AplikasiPadelPBO.git
cd AplikasiPadelPBO
```

2. Build project:
```bash
mvn clean install
```

3. Jalankan aplikasi:
```bash
mvn exec:java
```
